Для Windows

Работайте быстрее

SheetX для таблиц, ForDoc для документов, XTyping для печати и SecCorp для проверки файлов.

Windows

SheetX

Быстрый табличный редактор, совместимый с файлами и формулами Excel: 496 функций, сводные таблицы, диаграммы и условное форматирование. Работает без интернета и регистрации.

Windows

ForDoc

Редактор документов для DOCX, RTF, ODT, HTML, Markdown и обычного текста. Поддерживает стили, таблицы, изображения, проверку орфографии и экспорт в PDF. Работает локально без аккаунта.

Редактор документовОткрыть в Microsoft Store ↗
Windows

XTyping

Тренажёр печати с тестами на время, измеримой скоростью, статистикой и поддержкой собственных текстов и книг.

Тренажёр для печатиОткрыть в Microsoft Store ↗
Windows

SecCorp

Проверяет выбранные файлы и папки сигнатурным и эвристическим анализом. Может загружать базы ClamAV, а найденные угрозы помещать в локальный зашифрованный карантин. Ручной сканер, не постоянная защита системы.
